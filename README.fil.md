## Pag-install

I-download at i-extract ang buong proyekto at pangalanan ang folder na ai-prompt-optimizer. Ilagay ito sa isa lamang sa mga lokasyon ng skill sa ibaba. Dapat nasa loob mismo nito ang SKILL.md. Pagkatapos, magsimula ng bagong pag-uusap.

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

- Suriin: tukuyin ang mahahalagang salungatan o kakulangan at magmungkahi ng pinakamaliit na kailangang pagbabago.
