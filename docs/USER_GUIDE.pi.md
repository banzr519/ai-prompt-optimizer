## Inputs

Supply the goal, original material, non-negotiable constraints and completion criteria. Disclose missing attachments instead of guessing. Keep Pāli diacritics exactly where supplied.

## Advanced use

Use original prompt, actual answer and concrete feedback for targeted repair. Reusable variables, output contracts, comparisons and handoffs follow the shared rules. Without execution evidence, report only a static review.

## Bhāsā / Language

Specify Pāli and the required script. This entry uses Latin transliteration and is not a promise of support for every writing system. Pāli is distinct from Balinese and Bengali. Preserve commands, variables and JSON keys.

## Chat / Plain chat

Without a skill-capable client, paste the SKILL.md body after its YAML header and provide your task separately. Attach only necessary references. The skill name alone does not load local files.

## Problems / Troubleshooting

If the skill is missing, check its folder, location and client support, then start a new chat. Preserve custom changes before updating. If Pāli wording is uncertain, keep the source and explain the uncertainty rather than silently substituting another language.

## Sīmā / Limits

Experimental and AI-authored; not reviewed by a Pāli specialist. These short Pāli phrases and English explanations are a bilingual starter, not a full Pāli translation. Model proficiency is unverified. Request specialist review for consequential work; do not assume native-level accuracy.
