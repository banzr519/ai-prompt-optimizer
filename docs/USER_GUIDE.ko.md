## 필요한 정보

목표, 원본 자료, 변경하면 안 되는 내용, 완료 기준을 알려 주세요. 첨부파일이 없으면 누락 사실을 밝히고 추측으로 채우지 않습니다.

## 고급 사용법

원래 프롬프트, 실제 답변, 구체적인 오류를 제공하면 해당 부분을 수정할 수 있습니다. 변수 템플릿, JSON 출력 조건, 답변 비교, 대화 인계도 다룹니다. 실행 결과가 없으면 문면 검토만 합니다.

## 언어와 형식

설명, 개선된 지시문, 최종 결과물의 언어를 각각 지정할 수 있습니다. 변수, 명령어, JSON 키, 유지하도록 지정한 문구는 바꾸지 않습니다. 자료의 언어가 명시적인 출력 언어를 덮어쓰지 않습니다.

## 일반 채팅에서 사용

스킬을 지원하지 않는 채팅에서는 SKILL.md의 YAML 머리말 뒤 본문을 붙여 넣고 요청을 별도로 입력하세요. 필요한 참고 자료만 첨부합니다. 스킬 이름만 입력해도 파일이 자동으로 불러와지는 것은 아닙니다.

## 문제 해결

스킬이 보이지 않으면 폴더 구조, 설치 경로, 클라이언트 지원 여부를 확인하고 새 대화를 여세요. 업데이트 전에 사용자 수정 사항을 보관하세요. 답변이 길면 한 문단으로 요청할 수 있습니다.

## 범위와 검증

이 페이지는 AI가 작성한 현지화 입문 문서로, 원어민의 전문 교정을 받지 않았습니다. 결과는 모델과 클라이언트에 따라 달라집니다. 30개 언어 항목은 모든 모델에서 검증했다는 뜻이 아닙니다. 상세 유지보수·조사 문서는 주로 영어와 중국어 간체로 제공됩니다.
