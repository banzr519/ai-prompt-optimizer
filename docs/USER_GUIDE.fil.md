## Kailangang impormasyon

Ibigay ang layunin, orihinal na materyal, mga bagay na hindi dapat baguhin at pamantayan ng pagkumpleto. Sabihin kung may nawawalang kalakip; huwag hulaan ang laman nito.

## Mas advanced na paggamit

Ibigay ang orihinal na prompt, aktuwal na sagot at tiyak na mali para sa nakatuong pagwawasto. Maaari ring gumawa ng template na may variable, magtakda ng JSON, maghambing ng sagot o magpasa ng konteksto. Kung walang resulta ng pagsubok, teksto lamang ang masusuri.

## Wika at format

Maaaring magkahiwalay ang wika ng paliwanag, pinahusay na prompt at huling output. Panatilihin ang mga variable, command, JSON key at eksaktong siping kailangang manatili. Hindi pinapalitan ng wika ng sanggunian ang tahasang pagpili ng wika.

## Paggamit sa karaniwang chat

Sa chat na walang skill, i-paste ang katawan ng SKILL.md pagkatapos ng YAML header at ibigay nang hiwalay ang kahilingan. Isama lamang ang kailangang sanggunian. Hindi awtomatikong naglo-load ng mga file ang pangalan ng skill lamang.

## Paglutas ng problema

Kung hindi lumilitaw ang skill, suriin ang istruktura at lokasyon ng folder at suporta ng app, saka magbukas ng bagong chat. Ingatan ang sariling pagbabago bago mag-update. Humiling ng isang talata kung masyadong mahaba ang sagot.

## Saklaw at beripikasyon

Ang lokal na panimulang gabay na ito ay isinulat gamit ang AI at hindi pa propesyonal na nirepaso ng katutubong tagapagsalita. Nakasalalay ang resulta sa modelo at app. Ang 30 pagpipiliang wika ay hindi nangangahulugang nasubukan ang lahat ng modelo.
