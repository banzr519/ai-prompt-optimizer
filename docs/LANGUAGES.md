## Locale rules / 地区与语言规则

- Simplified and Traditional Chinese stay distinct; Traditional does not automatically imply a particular region. / 保留简繁体区别，不把繁体自动绑定某地区。
- pt-BR and pt-PT have separate entries; generic Portuguese follows the user’s preference. / 巴西与欧洲葡萄牙语分别提供入口。
- Pāli (`pi`), Balinese (`ban`) and Bengali (`bn`) are distinct. / 巴利语、巴厘语和孟加拉语分别处理。
- Commands, placeholders, JSON keys and exact required text remain unchanged. / 命令、变量、JSON 字段及指定原文不随语言自动翻译。
- [IANA language registry](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry) · [Rules](../references/languages.md) · [Validation](../evals/RESULTS-v2.3.0.md)

To maintain translations, edit [the catalog](../locales/catalog.json) and run `python3 scripts/build_localized_docs.py` from the repository. Use `--check` to detect drift. / 维护时修改目录数据，再运行脚本；使用 `--check` 检查生成文件是否一致。
