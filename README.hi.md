## स्थापना

पूरा प्रोजेक्ट डाउनलोड करके अनज़िप करें और फ़ोल्डर का नाम ai-prompt-optimizer रखें। नीचे दिए गए किसी एक स्किल स्थान पर रखें। SKILL.md सीधे उसी फ़ोल्डर में होना चाहिए। फिर नई बातचीत शुरू करें।

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## तीन तरीके

- केवल सुधार: कॉपी करने योग्य निर्देश बनाएँ, उसके भीतर का काम न करें।
- स्पष्ट करें और करें: आवश्यक बातें स्पष्ट करके अधिकृत काम पूरा करें।
- समीक्षा: महत्वपूर्ण विरोधाभास या कमियाँ बताएँ और न्यूनतम सुधार सुझाएँ।
