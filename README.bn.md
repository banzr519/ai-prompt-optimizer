## ইনস্টলেশন

সম্পূর্ণ প্রকল্প ডাউনলোড করে আনজিপ করুন এবং ফোল্ডারের নাম ai-prompt-optimizer দিন। নিচের স্কিল অবস্থানগুলোর একটিতে রাখুন। SKILL.md সরাসরি সেই ফোল্ডারে থাকতে হবে। এরপর নতুন কথোপকথন খুলুন।

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## তিনটি ব্যবহারপদ্ধতি

- শুধু উন্নত করুন: কপি করার মতো নির্দেশনা তৈরি করুন, ভেতরের কাজ সম্পাদন করবেন না।
- স্পষ্ট করে সম্পাদন করুন: প্রয়োজনীয় অস্পষ্টতা দূর করে অনুমোদিত কাজ করুন।
- পর্যালোচনা: গুরুত্বপূর্ণ বিরোধ বা ঘাটতি চিহ্নিত করে ন্যূনতম সংশোধন দিন।

## উদাহরণ

