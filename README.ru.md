**v2.3.0 · MIT · ru**

**Превращайте расплывчатые запросы в ясные инструкции для AI, сохраняя исходный смысл.**

Подходит для кода, дизайна, текстов, исследований, запросов на изображения и видео. Сохраняет числа, ограничения и переменные, отделяет факты от предположений. Исходная задача выполняется только по явному запросу.

## Установка

Скачайте и распакуйте весь проект, назовите папку ai-prompt-optimizer. Поместите её только в один из каталогов навыков ниже. Файл SKILL.md должен лежать непосредственно в ней. Затем откройте новый диалог.

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## Три режима

- Только улучшить: получить готовую инструкцию без выполнения описанной задачи.
- Уточнить и выполнить: прояснить необходимое и выполнить разрешённую работу.
- Проверить: выявить существенные противоречия и пробелы, предложить минимальные исправления.

## Пример

```text
$ai-prompt-optimizer Улучши только инструкцию, не выполняй задачу: Сделай отчёт профессиональнее, сохрани все факты и числа, не добавляй выводы, не подтверждённые материалами. Ответь по-русски.
```

## Границы и проверка

Это локализованное вводное руководство создано AI и не прошло профессиональную проверку носителем языка. Результат зависит от модели и клиента. 30 языковых разделов не означают тестирование всех моделей. Подробные материалы по сопровождению и исследованиям в основном доступны на английском и упрощённом китайском.
