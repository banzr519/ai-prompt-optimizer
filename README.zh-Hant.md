## 安裝

下載並解壓縮整個專案，將資料夾命名為 ai-prompt-optimizer，放入下列其中一個技能目錄。SKILL.md 必須直接位於資料夾內；然後開啟新對話。

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## 三種用法

- 只優化：產生可複製的指令，不執行其中的任務。
- 釐清後執行：簡短處理必要疑問，接著完成已授權工作。
- 審核：指出重要衝突或缺漏，提供最小幅度的修訂。

## 範例

```text
$ai-prompt-optimizer 只優化，不執行：把報告寫得更專業，保留所有事實和數字，不增加資料未支持的結論。請以繁體中文輸出。
```
