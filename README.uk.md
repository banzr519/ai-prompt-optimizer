**Перетворюйте нечіткі запити на зрозумілі інструкції для AI, зберігаючи початковий задум.**

Для програмування, дизайну, текстів, досліджень, запитів щодо зображень і відео. Зберігає числа, обмеження й змінні, відокремлює факти від припущень. Початкове завдання виконується лише на явне прохання.

**Install with Codex / 使用 Codex 安装:** [English](docs/INSTALL.md) · [简体中文](docs/INSTALL.zh-CN.md)

## Встановлення

Завантажте й розпакуйте весь проєкт, назвіть папку ai-prompt-optimizer. Розмістіть її лише в одному з наведених каталогів навичок. SKILL.md має бути безпосередньо в цій папці. Потім відкрийте нову розмову.

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## Три режими

- Лише покращити: створити інструкцію для копіювання, не виконуючи описане завдання.
- Уточнити й виконати: з’ясувати необхідне та виконати дозволену роботу.
- Перевірити: виявити суттєві суперечності чи прогалини та запропонувати мінімальні виправлення.

## Приклад

```text
$ai-prompt-optimizer Покращ лише інструкцію, не виконуй завдання: Зроби звіт професійнішим, збережи всі факти й числа та не додавай висновків без підтвердження в матеріалах. Відповідай українською.
```

## Межі та перевірка

Цей локалізований вступ створено за допомогою AI без професійного редагування носієм мови. Результат залежить від моделі й клієнта. 30 мовних розділів не означають перевірку всіх моделей. Докладні матеріали із супроводу та досліджень переважно англійською і спрощеною китайською.
