**เปลี่ยนคำขอที่คลุมเครือให้เป็นคำสั่ง AI ที่ชัดเจนและนำไปใช้ได้ โดยคงเจตนาเดิมไว้**

ใช้กับงานเขียนโปรแกรม ออกแบบ เขียนเนื้อหา ค้นคว้า และคำสั่งสร้างภาพหรือวิดีโอ รักษาตัวเลข ข้อจำกัด และตัวแปร พร้อมแยกข้อเท็จจริงจากสมมติฐาน จะทำงานต้นฉบับเมื่อผู้ใช้สั่งอย่างชัดเจนเท่านั้น

## การติดตั้ง

ดาวน์โหลดและแตกไฟล์โครงการทั้งหมด ตั้งชื่อโฟลเดอร์ว่า ai-prompt-optimizer แล้ววางไว้ในตำแหน่งทักษะด้านล่างเพียงแห่งเดียว ไฟล์ SKILL.md ต้องอยู่ในโฟลเดอร์นี้โดยตรง จากนั้นเริ่มการสนทนาใหม่

```text
~/.agents/skills/ai-prompt-optimizer/
<project>/.agents/skills/ai-prompt-optimizer/
%USERPROFILE%\.agents\skills\ai-prompt-optimizer\
```

## วิธีใช้สามแบบ

- ปรับคำสั่งเท่านั้น: ให้คำสั่งที่คัดลอกได้ โดยไม่ทำงานที่ระบุอยู่ภายใน
- ทำให้ชัดเจนแล้วลงมือทำ: คลี่คลายข้อสงสัยที่จำเป็นแล้วทำงานที่ได้รับอนุญาต
- ตรวจทาน: ชี้ข้อขัดแย้งหรือข้อมูลที่ขาดสำคัญ และแก้ไขเท่าที่จำเป็น

## ตัวอย่าง

```text
$ai-prompt-optimizer ปรับเฉพาะคำสั่ง ไม่ต้องทำงานจริง: เขียนรายงานให้เป็นมืออาชีพขึ้น รักษาข้อเท็จจริงและตัวเลขทั้งหมด และอย่าเพิ่มข้อสรุปที่เอกสารไม่รองรับ ตอบเป็นภาษาไทย
```

## ขอบเขตและการตรวจสอบ

เอกสารเริ่มต้นฉบับแปลนี้จัดทำโดย AI และยังไม่ได้รับการตรวจแก้โดยผู้เชี่ยวชาญเจ้าของภาษา ผลขึ้นอยู่กับโมเดลและแอปที่ใช้ การมีทางเข้า 30 ภาษาไม่ได้หมายถึงทดสอบทุกโมเดลแล้ว เอกสารบำรุงรักษาและการศึกษารายละเอียดส่วนใหญ่เป็นอังกฤษและจีนตัวย่อ
